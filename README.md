# 驼峰调车智能优化平台

铁路编组站驼峰纵断面与平面布置的多目标自动优化工具，用于快速生成满足**难行车溜放到位、易行车安全连挂**约束的纵断面与平面展开方案。

## 功能模块

1. **设计输入** —— 三基准车（难/中/易行车）、股道数、阻力系数等参数
2. **多目标优化** —— PSO / ALNS / NSGA-II 自动寻优
3. **平面展开图** —— 溜放线平面布置一键生成（道岔 / 减速器 / 曲线）
4. **纵断面方案** —— 凹形「前陡后缓」纵断面与峰高设计
5. **车流适应性** —— 蒙特卡洛模拟车流溜放与安全连挂
6. **检算报告** —— 规范约束逐项自动校核
7. **结果存档** —— 方案本地保存、导出与载入

## 使用说明

直接用浏览器打开 `index.html` 即可，无需安装任何依赖、无需联网。

- 封面页 → 「进入平台」开始使用
- 「查看源代码」可查看当前网页完整源代码

## 技术说明

- 单文件自包含 HTML（内联样式 + 原生 JavaScript + 手写 SVG），零依赖
- 依据《铁路站场及枢纽》教材 & TB 10062-2018 规范
- 道岔位置固定布设、不参与优化
